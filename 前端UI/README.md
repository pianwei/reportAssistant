<https://pianwei.shadlc.net/due-diligence/> 的实际页面为截图基准。

## 目录结构

```text
前端UI/
├─ 源码/                    仅保留与 UI 直接相关的参考源码
│  ├─ README.md             正式前端接入说明
│  ├─ src/pages/            用户端与运营端页面
│  ├─ src/components/       结果卡片组件
│  ├─ src/styles.css        基础布局、聊天气泡、运营端样式
│  ├─ src/unified.css       结果卡片、引导卡片、问题衍生样式
│  ├─ src/main.ts           原页面入口和路由关系
│  └─ src/api.ts            页面请求方式参考
├─ UI截图/                  线上页面关键状态截图
└─ 样式规范/
   ├─ UI样式说明.md          组件、状态、接口和部署说明
   └─ 卡片与追问气泡.css     可供其他前端工程直接参考的独立样式片段
```

## 源码使用方式

`源码` 目录不是可独立安装的完整工程，不包含依赖、构建、测试和部署配置。正式前端应阅读
`源码/README.md`，将需要的页面、组件及 CSS 接入自己的工程。

## 当前首页布局

- 顶部仅保留右侧“新建会话”按钮，不再提供前端历史对话入口。
- 左侧为大尺寸“智能案例推荐”主卡片。
- 右侧上方为固定的“猜你想问”，不提供“换一批”。
- 右侧下方为多维筛选、数据统计、比赛问答三个功能入口。

> 运营后台 `/ops` 的源码一并交付；线上入口受网关鉴权保护，本包未包含后台线上截图。
